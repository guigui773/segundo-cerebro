# Evidências do notebook

Adicione nesta pasta capturas de tela reais do notebook que mostrem:

- a pergunta feita;
- a resposta produzida;
- as fontes citadas pelo notebook.

Não crie capturas ilustrativas para substituir evidências reais. Antes de compartilhar, confira se as imagens não expõem dados pessoais ou informações privadas.
