# Checklist antes da entrega

## Repositório
- [ ] O repositório está na conta correta.
- [ ] O nome é legível, em minúsculas e sem acentos: `segundo-cerebro`.
- [ ] A visibilidade do repositório está como **Public**.
- [ ] O README aparece na página inicial.

## Notebook
- [ ] O link compartilhado abre em uma janela anônima.
- [ ] O notebook não expõe dados pessoais ou conteúdo que não possa ser compartilhado.
- [ ] A diretriz de responder com base nas fontes está registrada no notebook.
- [ ] A resposta à pergunta foi registrada a partir do notebook real.
- [ ] As fontes citadas foram conferidas e sustentam as afirmações relevantes.

## Materiais e evidências
- [ ] O mapa mental PNG foi adicionado em `materiais/`.
- [ ] Os slides PDF foram adicionados em `materiais/`.
- [ ] Capturas reais de perguntas, respostas e citações foram adicionadas em `evidencias/`.
- [ ] Todos os arquivos mencionados existem e abrem corretamente.
- [ ] Nenhuma captura, resposta ou citação foi inventada para preencher lacunas.

## Entrega
- [ ] Enviar o link do repositório público, não apenas o link do notebook.
